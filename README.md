# ميلانو رانك — الدعم والخصوصية

نفس التصميم الحديث الموجود في معاينة الموقع، مع البريد **alhal.iraq@gmail.com** وبطاقات البريد وواتساب والأسئلة الشائعة وصفحة الخصوصية.

[معاينة التصميم](https://milano-rank-support.mightynectarine1.chatgpt.site/)

## الملفات الجاهزة للنشر

الصفحات والأصول موجودة الآن في جذر المستودع، ويمكن رفعها مباشرة إلى مجلد الموقع في Hostinger.

- `index.html`: الصفحة الرئيسية
- `support/index.html`: صفحة الدعم
- `privacy/index.html`: سياسة الخصوصية
- `style.css`: تنسيق التصميم المتجاوب
- `Cairo.ttf` و`OFL.txt`: الخط العربي وترخيصه
- `icon.png`: أيقونة ميلانو

توجد نسخة إضافية في `dist/` للتوافق مع الحزمة السابقة.

## المعاينة المحلية

```sh
python3 -m http.server 8765
```

## GitHub Pages

عند اختيار النشر من فرع، استخدم `main` والمجلد `/ (root)`.

صفحة المستودع تعرض الملفات؛ لمعاينة الواجهة استخدم استضافة ويب.
